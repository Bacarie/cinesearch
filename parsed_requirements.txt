1. Contexte et Objectifs
Contexte
Vous êtes développeur dans une startup spécialisée dans le divertissement numérique. L'entreprise souhaite créer un service de recommandation et de recherche de films pour ses utilisateurs. Elle dispose d'un dataset de près de 5 000 films contenant des informations riches : titre, réalisateurs, acteurs, genres, synopsis, note, date de sortie, durée, etc.
Votre mission est de construire un moteur de recherche performant exploitant Elasticsearch comme backend de recherche, avec une interface en ligne de commande développée en Python. Le tout sera déployé via Docker pour garantir la portabilité et la reproductibilité de l'environnement.
Objectifs pédagogiques
À l'issue de ce projet, vous serez capables de :
Déployer une stack Elasticsearch + Kibana avec Docker Compose
Concevoir un mapping Elasticsearch adapté à un jeu de données réel
Indexer un volume conséquent de données via l'API bulk de Python
Écrire des requêtes de recherche variées avec le Query DSL (match, bool, fuzzy, prefix...)
Exploiter les agrégations Elasticsearch pour produire des statistiques avancées
Construire un dashboard Kibana interactif pour la visualisation de données
Développer une interface CLI Python ergonomique et robuste

Pour une explication détaillée de Docker et de son fonctionnement, référez-vous au document de cours (Cours Complet Elasticsearch) qui contient une section dédiée à la conteneurisation et à Docker.
Alternative si vous ne pouvez pas installer Docker : Si vous rencontrez des difficultés pour installer Docker sur votre machine (restrictions administrateur, espace disque insuffisant, compatibilité matérielle...), vous pouvez utiliser Docker Play (labs.play-with-docker.com). Cette plateforme en ligne gratuite vous fournit un environnement Docker temporaire (4 heures par session) directement dans votre navigateur, sans rien installer sur votre ordinateur. Vous pourrez y exécuter vos conteneurs Elasticsearch et Kibana normalement.

Exigences :
Parser correctement le fichier JSON au format bulk (lignes alternées : métadonnées / document)

Important : Le dataset fourni est au format bulk Elasticsearch. Chaque document est précédé d'une ligne de métadonnées d'index. Les données du film sont dans le champ "fields" de chaque document. Votre script doit extraire correctement ces données.
Structure d'un document dans le fichier :
Format du fichier JSON
// Ligne 1 : métadonnées (à ignorer ou utiliser pour l'ID)
{"index":{"_index": "movies","_type":"movie","_id":1}}
// Ligne 2 : document (les données sont dans "fields")
{"fields": {"title": "Don Jon", "rating": 7.4, ...}, "id": "tt2229499", "type": "add"}
Note : Le champ `_type` est un vestige des anciennes versions d'Elasticsearch (< 7.x). Il est ignoré dans ES 8.x. Votre code d'indexation doit ignorer ce champ lors du parsing.
Exemple de code d'indexation bulk :
Python — indexer.py (extrait)
from elasticsearch import Elasticsearch
from elasticsearch.helpers import bulk
import json
import time
def index_movies(es, filename, index_name="movies"):
    start = time.time()
    actions = []
    
    with open(filename, "r", encoding="utf-8") as f:
        lines = f.readlines()
    
    for i in range(1, len(lines), 2):
        doc = json.loads(lines[i].strip())
        movie = doc["fields"]
        actions.append({
            "_index": index_name,
            "_source": movie
        })
    
    try:
        success, errors = bulk(es, actions, raise_on_error=False)
        print(f"{success} films indexés avec succès")
        if errors:
            print(f"{len(errors)} erreurs rencontrées")
    except Exception as e:
        print(f"Erreur lors de l'indexation : {e}")
    
    elapsed = time.time() - start
    print(f"Temps total: {elapsed:.2f}s")

3.2 Recherche avancée multi-critères (10 pts)
Fonction : search_advanced(title, actor, director, genre, min_rating, max_rating, year_from, year_to)
Implémenter une recherche multi-critères utilisant une bool query. Tous les paramètres sont optionnels (valeur par défaut None). La requête doit se construire dynamiquement en fonction des paramètres fournis.
Construction de la requête :
title : clause must avec match query
actor : clause must avec match sur le champ actors
director : clause must avec match sur le champ directors
genre : clause filter avec term query sur genres
min_rating / max_rating : clause filter avec range query sur rating
year_from / year_to : clause filter avec range query sur year
Python — search.py (extrait)
def search_advanced(es, title=None, actor=None, director=None,
                    genre=None, min_rating=None, max_rating=None,
                    year_from=None, year_to=None, index="movies"):
    must = []
    filters = []
    
    if title:
        must.append({"match": {"title": title}})
    if actor:
        must.append({"match": {"actors": actor}})
    if director:
        must.append({"match": {"directors": director}})
    if genre:
        filters.append({"term": {"genres": genre}})
    
    rating_range = {}
    if min_rating is not None:
        rating_range["gte"] = min_rating
    if max_rating is not None:
        rating_range["lte"] = max_rating
    if rating_range:
        filters.append({"range": {"rating": rating_range}})
    
    # Construire la bool query...
    query = {"bool": {"must": must, "filter": filters}}
    return es.search(index=index, query=query)

9. Conseils et Indices
Méthodologie recommandée
Suivez cet ordre pour avancer efficacement dans le projet :
Étape 1 — Infrastructure : Commencez par le docker-compose.yml. Vérifiez que Elasticsearch et Kibana démarrent correctement et sont accessibles.
Étape 2 — Mapping : Créez le mapping de l'index. Testez-le dans Kibana Dev Tools avant de le coder en Python.
Étape 3 — Indexation : Développez le script d'indexation. Commencez par indexer quelques documents avant de passer au bulk complet.
Étape 4 — Recherches : Implémentez les fonctions de recherche une par une. Testez chaque requête dans Kibana Dev Tools d'abord.
Étape 5 — Agrégations : Ajoutez les fonctions de statistiques et d'analyse.
Étape 6 — CLI : Construisez le menu interactif qui lie le tout.
Étape 7 — Kibana : Créez le dashboard en dernier, une fois que toutes les données sont indexées.
Astuces techniques
Utilisez pprint pour débugger les réponses JSON volumineuses d'Elasticsearch
Testez vos requêtes dans Kibana Dev Tools (Console) avant de les coder en Python — c'est beaucoup plus rapide pour itérer
Pour le bulk indexing, traitez les documents par lots de 500 à 1000 pour éviter les timeouts
Pensez à rafraîchir l'index après l'indexation : es.indices.refresh(index="movies")
Utilisez try/except autour de vos appels Elasticsearch pour gérer les erreurs proprement
Pour les agrégations imbriquées, construisez la requête étape par étape et testez à chaque niveau
Le module tabulate peut être utile pour formater les résultats en tableau dans le CLI
